# 0005 — Record significant decisions in `docs/decisions/`

**Date:** 2026-11-06 · **Status:** accepted · **Proposed by:** agent, accepted by the human

## Context
The overview from `/define` ruled out a decisions file. The repo kit requires one, and the harness now allows it. This repo is expected to go public, and a fresh history would lose reasons held only in commit messages.

## Decision
Keep records for significant decisions. The planes stay the authority, and an outdated record gets superseded.

## Alternatives considered
- Commit messages only: lost on a fresh history.

## Consequences
The risk the original rule named remains, and it depends on superseding records when they stop applying.
